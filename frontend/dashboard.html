Descarga el instalador para Windows y comienza a crear clips virales.

Descargar para Windows

Versión para Windows 10/11. Requiere 8 GB de RAM mínimo.

📋 Requisitos del sistema

  • ✓ Windows 10/11 (64 bits)
  • ✓ Python 3.10 – 3.13 (se instala automáticamente si no está)
  • ✓ 8 GB de RAM mínimo (16 GB recomendado)
  • ✓ 5 GB de espacio libre en disco
  • ✓ Conexión a internet (solo para la primera instalación)
  • ✓ GPU NVIDIA opcional (acelera la transcripción con CUDA)
  • ✓ Navegador moderno (Chrome, Edge, Firefox)
  • ✓ Licencia activa (key proporcionada tras el pago)
